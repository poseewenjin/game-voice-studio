# 团队章程与 SOP（team-sop.md）

game-voice-studio 是一支 **6 人专家团**：4 名必修团员 + 1 名可选团员 + 1 名门禁质检官。本文件是团队的正式职责定义与标准操作流程（SOP）；SKILL.md 中的「角色0-4 / 可选前置 / 自审闸门」是各环节的操作细节。

## 一、团队构成

| 编号 | 团员 | 一句话定位 | 必经 |
| --- | --- | --- | --- |
| 0 | 选题策划师 | 素材入口的侦察兵：找热点、出候选清单、提示二创版权 | 可选（用户要选题时） |
| 1 | 画面分析师 | 唯一有权描述「画面里发生了什么」的人 | ✅ |
| 2 | 文案师 | 把时间轴翻译成「能说出口的人话」 | ✅ |
| — | 质检官（自审闸门） | 文案出厂前的唯一门禁，一票否决 | ✅（文案→配音之间） |
| 3 | 配音导演 | 让人设的声音把文案念出来 | ✅ |
| 4 | 剪辑师 | 把声音和画面按时间轴焊成成片 | ✅ |

## 二、团员职责卡

### 团员0 · 选题策划师（可选）
- **定位**：素材入口的侦察兵
- **核心职责**：通用搜索并行查 Steam 热销/新品、Epic 免费、TapTap 热门、当日游戏新闻；整理候选清单；标注来源与风险；提示二创版权
- **输入**：用户「要选题」意图
- **输出**：候选选题清单（游戏名 | 热度来源 | 公开事实 | 建议解说角度 | 风险提示）
- **验收标准**：每项有来源标注；事实与建议分离；无未核实断言
- **无权做**：替用户决定素材；把榜单当事实结论
- **异常处理**：搜索无结果 → 如实说明并给出替代渠道建议

### 团员1 · 画面分析师
- **定位**：唯一有权描述「画面里发生了什么」的人
- **核心职责**：probe 元信息；游戏高光分析（时间戳+OCR+画面描述）；按需补故事线/OCR/抽帧核实；产出场景时间轴；区分「已核实/推测」
- **输入**：原视频
- **输出**：`01_analysis/画面分析摘要.md`（场景时间轴：窗口起止 | 画面内容 | 高光类型）
- **验收标准**：时间轴覆盖全片；每个关键时刻有窗口起止；事实标注证据层级（高光模型/OCR/抽帧核实）
- **无权做**：写文案、替文案师下判断
- **异常处理**：视频打不开/格式不支持 → 先 `transcode-video` 再分析；置信度低 → 标注并抽帧核实

### 团员2 · 文案师
- **定位**：把时间轴翻译成人话
- **核心职责**：定人设（记忆库 > 新描述 > 模板 > 默认）；查游戏知识库校验专有名词；按结构模板写文案；每段绑定场景窗口；配速校验全段 ok；生成文案稿+字幕
- **输入**：`01_analysis` 场景时间轴 + 人设卡 + 游戏知识库
- **输出**：`02_script/解说文案稿.md` + `subtitles.srt/.json`
- **验收标准**：段段绑定窗口；字数符合配速；专有名词有据；结构完整（钩子→背景→过程→高潮→收尾）
- **无权做**：跳过自审直接配音；把「推测」写成事实；使用未确认的「首播/独家」表述
- **异常处理**：画面证据不足 → 退回分析师补抽帧；知识库缺词条 → 询问用户或检索后入库

### 质检官（自审闸门）
- **定位**：文案出厂前的唯一门禁，一票否决
- **核心职责**：四查——合规（不低俗/不引战/不剧透/敏感表述已确认）、人设一致（抽查≥3处）、画面事实（与时间轴交叉核对）、配速（timing_planner 全段 ok）
- **输入**：文案稿 + 分析摘要 + 人设卡
- **输出**：自审结论（通过 / 退回+问题清单），一句话记入文案稿末尾
- **验收标准**：每项有明确判定依据；不静默放行
- **无权做**：代写文案（只退回不代改）；放行未通过项
- **异常处理**：退回超 2 轮 → 标注未通过项交付，交用户裁决

### 团员3 · 配音导演
- **定位**：声音的执行导演
- **核心职责**：选音色（参考人声克隆 / 预设）；逐段生成口播；probe 每段实际时长；超差纠偏（删减重生成 / ±5% 调速）；拼接全轨
- **输入**：文案稿 + 人设卡 + 参考人声（如有）
- **输出**：`03_voice/段_<n>.wav` + `旁白全轨.wav` + 各段实际时长记录
- **验收标准**：每段时长 ≤ 窗口+0.5s；音色与所选人设一致；无吞字漏句
- **无权做**：改文案文字（只能建议回文案师）；跳过时长校验
- **异常处理**：生成失败 → 按错误调整 prompt 重试（≤2次）；时长反复超差 → 回文案师删减

### 团员4 · 剪辑师
- **定位**：把声音和画面焊死的成片师
- **核心职责**：读成片预设；按场景 trim →（竖屏裁切）→ 音轨组装（旁白/BGM/原声）→ mux → 字幕压制 → concat → fade；交付成片与参数记录
- **输入**：原视频 + 段配音 + 字幕 + 成片预设
- **输出**：`04_final/成片.mp4` + 所用预设与最终参数
- **验收标准**：音画同步（抽查≥2 个时间点）；预设参数全部落实；成片时长 ≈ 原视频
- **无权做**：改台词/换音色（回对应团员）；静默降级预设（如 BGM 不支持必须告知用户）
- **异常处理**：合流时长不一致 → 按需对齐；某预设项工具不支持 → 明确告知并给替代方案

## 三、团队协作协议（交接规则）

1. **只信交付物**：下游只读取上游落盘文件，不靠对话记忆转述。
2. **命名即契约**：目录固定（01_analysis / 02_script / 03_voice / 04_final），文件命名固定，下游按名取用。
3. **上游不完，下游不动**：没有分析摘要文案师不开工；没有全段 ok 不配音；没有自审通过不合成。
4. **事实优先**：意见不一致时，以画面核实事实（时间轴/抽帧）为准，人设表达其次。
5. **异常上报**：任一团员卡住超 2 次 → 上报用户，说明卡点与已试方案，不静默降级。
6. **留痕**：每阶段验收一句话写入交付说明（谁、做了什么、验了什么）。

## 四、SOP 标准操作流程

```
[触发] 用户意图
   ↓ 入口分流（决策点：全流程 / 只文案 / 只配音 / 只分析 / 只选题）
[可选] 团员0 选题策划 → 候选清单 → 用户选定素材
   ↓
团员1 画面分析 → 01_analysis（场景时间轴）
   ↓
团员2 文案 → 02_script（文案 + 字幕）
   ↓
质检官 自审闸门（门禁：四查全过才放行；退回 ≤2 轮）
   ↓
团员3 配音 → 03_voice（段 + 全轨 + 时长）
   ↓
团员4 剪辑 → 04_final 成片
   ↓
[交付] 交付清单全部到位 + 验证（回读 / 时长 / 字幕 / 人设 / 预设）
```

| 阶段 | 负责人 | 输入 | 动作 | 输出 | 验收 | 失败处理 |
| --- | --- | --- | --- | --- | --- | --- |
| 分流 | 代理（总管） | 用户意图 | 判定执行路径 | 路径指令 | 路径与意图一致 | 拿不准按全流程执行并说明 |
| 选题（可选） | 团员0 | 意图 | 搜索+整理 | 候选清单 | 有来源、事实建议分离 | 搜索失败→给替代渠道 |
| 分析 | 团员1 | 原视频 | 高光/OCR/抽帧核实 | 分析摘要 | 时间轴覆盖全片、证据分级 | 格式不支持→先转码 |
| 文案 | 团员2 | 时间轴+人设+知识库 | 写文案+配速校验 | 文案稿+字幕 | 段段绑窗、全段 ok | 证据不足→回分析师 |
| 门禁 | 质检官 | 文案+摘要+人设 | 四查 | 通过/退回清单 | 有依据、不静默 | 2 轮不过→交用户裁决 |
| 配音 | 团员3 | 文案+人设+参考声 | 逐段生成+时长纠偏 | 段 wav+全轨 | 时长≤窗口+0.5s、无吞字 | 反复超差→回文案师 |
| 剪辑 | 团员4 | 原视频+配音+字幕+预设 | 裁剪/混音/合流/字幕/拼接 | 成片+参数记录 | 音画同步、预设全落实 | 工具不支持→告知用户 |
| 交付 | 代理（总管） | 全部产物 | 清单核对+验证 | 交付说明 | 见下「完工标准」 | 缺口→标注并说明 |

## 五、完工标准（Definition of Done）

- 四层交付物全部落盘且命名规范；
- 自审有结论；预设参数有记录；
- 验证项抽查通过：音画同步≥2 个时间点、成片时长≈原视频、字幕逐段一致、人设抽查≥3 处、预设参数落实；
- 未解决项明确标注（不静默放行）。
