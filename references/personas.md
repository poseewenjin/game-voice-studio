# 人设库（personas.md）

配音与文案共用人设。人设 = 说话方式（语气/语速/口癖/句式）+ 立场视角（观众称呼、情绪曲线）。文案师按人设写词，配音导演按人设指定朗读方式。

## 人设参数 Schema

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| 身份称呼 | 解说自称，标题/开场用 | 「老司机阿K」 |
| 语气基调 | 激情 / 沉稳 / 整活 / 高冷 / 技术流 | 激情 |
| 语速(字/秒) | 解说 5.0–6.0；旁白 3.5–4.5 | 5.5 |
| 称呼观众 | 段首/互动用 | 兄弟们 |
| 口头禅/口癖 | 0–3 个，每 2–3 段用一次 | 「这波不亏」「稳了稳了」 |
| 句式偏好 | 短句 / 反问 / 悬念停顿 / 数据流 | 短句+反问 |
| 情绪曲线 | 全片情绪怎么走 | 先压后扬，翻盘时顶到最高 |
| 禁区 | 绝对不说的内容 | 不剧透、不念错角色名、不低俗 |

## 模板 A · 激情解说·老司机（默认）

- 身份称呼：老司机；语气：激情、上扬、节奏快；语速 5.5 字/秒
- 称呼观众：兄弟们；口癖：「这波不亏」「秀啊」「稳住，别急」
- 句式：短句、反问、感叹；情绪曲线：开局拉满，操作处爆点，收尾一句金句
- 禁区：不骂人不贬低对手选手，不剧透

## 模板 B · 沉浸旁白·说书人

- 身份称呼：说书人；语气：沉稳、叙事、留白；语速 4.0 字/秒
- 称呼观众：各位；口癖：无或「话说回来」
- 句式：长句铺陈+短句落点，善用悬念停顿；情绪曲线：铺垫→暗涌→爆发→余韵
- 适用：剧情向游戏、RPG 流程、氛围切片

## 模板 C · 整活综艺·玩梗人

- 身份称呼：整活区UP主；语气：诙谐、夸张、自嘲；语速 5.0 字/秒
- 称呼观众：家人们；口癖：「家人们谁懂啊」「节目效果」
- 句式：对比反差、玩梗（原创梗，不搬他人文案）、夸张比喻
- 禁区：梗必须原创表达，不抄袭网络原句；不低俗

## 模板 D · 技术流复盘·教练

- 身份称呼：教练；语气：冷静、专业、拆解；语速 4.8 字/秒
- 称呼观众：各位选手；口癖：「关键点在于」
- 句式：问题→原因→操作建议，善用术语+数据
- 禁区：术语必须准确，不确定的操作不硬解释

## 自定义人设

用户给出人设描述时，按下述规则提取成参数表（写入文案稿头部，供配音导演复用）：

1. 从描述里直接摘出：语气词、口头禅、称呼、语速要求（没给就用 5.0 默认并注明）。
2. 描述里的「风格关键词」映射到模板：激情/热血/炸→A；温柔/叙事/沉浸→B；搞笑/整活/抽象→C；专业/复盘/教学→D；混合风格取主模板再叠加对方模板的个别特征。
3. 把提取结果按上表字段写成「人设卡」，文案和配音都引用同一张人设卡，保证一致性。
4. 用户没有给参考人声音频时，配音导演按人设卡里的语气基调从预设音色里选（男/女、沉稳/清亮），并在交付里注明所用音色。
